# الحدود الإدارية

يهيّئ تبويب **Admin Boundaries** طبقة الحدود الإدارية في Climweb انطلاقًا من **مجموعات البيانات التشغيلية المشتركة لمكتب OCHA ‏(COD-AB)** المنشورة على [HDX](https://data.humdata.org/). هذه الميزة مستقلة عن كتالوج طبقات WMS: فهي تغذّي *مدير الحدود* (boundary manager) في Climweb الذي يقدّم الحدود على شكل **بلاطات متجهية (MVT)**.

## المتطلبات

- يجب تعيين **البلد** في [إعدادات الإضافة](./settings.md) (تبويب *Settings*). تُستخدم رموز ISO ألفا-2 وألفا-3 لتحديد البيانات وتصفيتها.
- يجب أن تتضمّن نسخة Climweb *مدير الحدود* (`adminboundarymanager`) و`geopandas`. وإلا فسيظهر تحذير ويُعطَّل زر الاستيراد.

## استيراد الحدود

انقر على **Import boundaries from OCHA**. تنفّذ الإضافة السلسلة كاملةً تلقائيًا:

1. **تحديد** مجموعة بيانات COD-AB على HDX عبر واجهة CKAN ‏(`cod-ab-<iso3>`) واختيار أرشيف shapefile ‏(`*.shp.zip`).
2. **تنزيل** الأرشيف الشامل (يحتوي على ملف shapefile واحد لكل مستوى إداري).
3. **استخراج** المستويات والكشف عنها (`adm0`، `adm1`، …)؛ مع تجاهل طبقات الخطوط والنقاط والعواصم.
4. **توحيد أعمدة** كل مستوى وفق المخطط الذي يتوقّعه مدير الحدود (`ADM{n}_EN`/`ADM{n}_FR` و`ADM{n}_PCODE`)، وإعادة الإسقاط إلى EPSG:4326، ومطابقة `ADM0_PCODE` مع رمز البلد.
5. **إعادة الضغط لكل مستوى** ثم **تحميل** كل مستوى في مدير الحدود.

> يُسجَّل البلد أولًا في إعدادات مدير الحدود، وإلا فإن إشاراته ستحذف الصفوف المُدرَجة.

عند الانتهاء، تلخّص لوحة عدد المعالم المُحمّلة لكل مستوى:

```
Boundaries imported: 4 level(s), 416 features
```

## المستويات المحمّلة

يعرض جدول **Loaded admin levels** عدد المعالم في كل مستوى للبلد المُهيأ:

| المستوى | المحتوى المعتاد |
|---------|------------------|
| 0 | البلد |
| 1 | المناطق |
| 2 | المقاطعات / الإدارات |
| 3 | البلديات |
| 4 | (حسب البلد) |

## معاينة الخريطة

تعرض الخريطة في أسفل التبويب الحدود التي يقدّمها مدير الحدود على شكل بلاطات متجهية:

```
/api/admin-boundary/tiles/{z}/{x}/{y}
```

وتتمركز تلقائيًا على المربع الحاوي للبلد. بعد الاستيراد، تُحدَّث الخريطة لعرض البيانات المُحمّلة حديثًا.

## إعادة الاستيراد والحذف

- **إعادة الاستيراد** عملية مُتكافئة: لكل مستوى، تُستبدل الحدود المُحمّلة سابقًا لهذا البلد.
- يحذف **Clear boundaries** جميع حدود البلد المُهيأ (كل المستويات). لا يمكن التراجع عن هذا الإجراء.

## مصدر البيانات

المصدر هو **OCHA COD-AB** ‏(Common Operational Datasets – Administrative Boundaries)، وهي الحدود الإدارية المرجعية التي تستخدمها الوكالات الإنسانية، والمنشورة على HDX.

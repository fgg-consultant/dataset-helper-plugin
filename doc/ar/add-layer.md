# إضافة طبقة يدويًا

يفتح زر **+ Add Layer** (شريط أدوات *Layer Catalog*) نموذجًا لإدراج طبقة في الكتالوج ليست موجودة في الكتالوج المدمج ولا تأتي من استيراد WMS.

تحمل الطبقات المضافة بهذه الطريقة الأصل **`manual`**: لا تُلمس أبدًا من قبل تحديثات الكتالوج المدمج وتبقى في الكتالوج طالما لم تحذفها.

## الحقول

| الحقل               | إلزامي | الوصف                                                                |
|---------------------|:------:|----------------------------------------------------------------------|
| **Category**        | ✔      | عنوان الفئة. ينشئ الفئة إذا لم تكن موجودة، وإلا يربط بها الطبقة الجديدة. |
| **Subcategory**     | ✔      | نفس الشيء على مستوى الفئة الفرعية.                                    |
| **Title**           |        | الملصق المعروض. إذا كان فارغًا، يُستخدم معرّف طبقة WMS.               |
| **WMS Layer Name**  | ✔      | المعرّف الدقيق للطبقة كما يظهر في GetCapabilities WMS (معامل `LAYERS`). |
| **WMS Base URL**    | ✔      | عنوان URL الأساسي لخدمة WMS، دون معاملات الاستعلام.                   |
| **Source**          |        | المنتج / المنظمة مصدر البيانات. منسوخ إلى `Metadata`.                |
| **Resolution**      |        | الدقة المكانية (`1km`, `0.05deg`، إلخ.). منسوخة إلى `Metadata`.       |

انقر على **Add**: تُنشأ المدخلة فورًا بالحالة `pending_add` 🟠. تظهر في الشجرة في الفئة والفئة الفرعية المحددتين.

## الخطوة التالية

انقر على **Synchronize with Climweb** لتهيئة الطبقة فعليًا.

## تعديل أو حذف طبقة مضافة

تُدار طبقة `manual` كأي مدخلة كتالوج أخرى:

- **تعطيلها** (إلغاء تحديدها) سيعلّمها `pending_remove`؛ ستحذف المزامنة التالية `Dataset` من جانب Climweb.
- **إعادة تفعيلها** يعيدها إلى `pending_add`؛ ستعيد المزامنة التالية إنشاءها.

لتعديل URL أو المعاملات، الأبسط هو تعطيل القديمة وإضافة جديدة. يتم التحرير الدقيق لـ `Dataset` المُهيّأ مباشرة في إدارة Wagtail (لكنه سيُعتبر *local drift* — راجع [التحديثات](./updates)).
